# Changelog

All notable changes to `@superslate/avatar` are documented here.

## [0.1.0] - 2026-11-22

- Initial public open-source release with 6 shape families, 40 curated palettes, OKLCH tone controls, dedicated light/dark appearance grammar, grapheme-safe initials overlay, React component (`@superslate/avatar/react`), CLI (`superslate-avatar`), and live Avatar Studio (`avatars.superslate.dev`).
